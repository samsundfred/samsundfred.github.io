```text
Create a complete HTML page that matches my existing GitHub Pages website design.

Design style:
- Modern developer portfolio aesthetic
- Dark futuristic theme
- Background with a deep navy/black radial gradient
- Glassmorphism cards with blurred transparent backgrounds
- Soft glowing effects
- Rounded corners (20-25px)
- Clean, minimal, professional look
- Similar to a personal .dev domain homepage
- Smooth hover animations
- Mobile responsive

Color palette:
- Background: #020617 and #1e3a8a
- Primary accent: #38bdf8 (cyan)
- Secondary accent: #a78bfa (purple)
- Text: white
- Secondary text: #cbd5e1 / #94a3b8

Typography:
- Use Segoe UI, Arial, or a similar modern sans-serif font
- Large gradient headings using:
  background: linear-gradient(90deg,#38bdf8,#a78bfa);
  -webkit-background-clip: text;
  color: transparent;

UI style:
- Use glass cards:
  background: rgba(255,255,255,0.08);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255,255,255,.15);

- Cards should:
  - Have rounded corners
  - Lift slightly on hover
  - Have smooth transitions
  - Feel like a premium app/dashboard interface

Layout:
- Centered content
- Good spacing
- Responsive grid where needed
- Works directly on GitHub Pages
- Use only HTML and CSS unless JavaScript is specifically requested

Site identity:
This is part of my GitHub Pages developer website:
[YOUR SITE NAME]

Page being created:
[DESCRIBE PAGE HERE]

Required sections:
[LIST SECTIONS HERE]

Links:
[ADD LINKS HERE]

Extra features:
[OPTIONAL: animations, buttons, icons, search, app cards, etc.]

Make the final result a complete standalone `index.html` file that I can upload directly.
```

Examples of using it:

**For a new app launcher:**

```
Page being created:
An app marketplace page showing all my projects.

Required sections:
- Hero title
- App cards
- App icons
- Open buttons
```

**For a tools page:**

```
Page being created:
A developer tools dashboard.

Required sections:
- Tool cards
- Categories
- Search bar
- Links to tools
```

**For a blog:**

```
Page being created:
A futuristic developer blog page.

Required sections:
- Article cards
- Dates
- Categories
- Featured article
```

Using this prompt should keep every new page looking like it belongs to the same website instead of starting a new design every time.
